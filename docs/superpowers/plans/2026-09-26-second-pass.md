Select Python, STM32, C++, Power BI, or Verilog; the hero worksheet shows actual project/experience/certificate references and corresponding artifacts receive a restrained evidence mark. The skills area offers the same trail. Use real anchors, keyboard-operable buttons, visible status, no pointer tracking, and readable defaults without JavaScript. - Pipeline steps use ordered labels instead of cryptic symbols. Each selection exposes input, decision, and output from current verified project content; a static completed-path line makes the trace clear. Arrow keys support selection, and transitions remain subtle/reduced-motion aware.
- Certificates remain physical documents. Allocate a wider document position to DEPI instead of shrinking its landscape artwork, improve metadata readability, and lighten the viewer close control while preserving its 44 px hit target. Use natural image height to remove letterboxing and excess blank space on mobile.
- Admin: real responsive project records below 901 px, alongside a desktop table. Both consume the same existing inventory. Title dominates; category/year, default/custom, and archived status are explicit. Shared handlers retain edit/archive/restore/delete semantics. Common navigation precedes a lower-prominence, clearly non-destructive maintenance action. No whimsical admin effects.
- Readability: practical metadata sizes and comfortable mobile body copy. Theme switching must not interpolate old backgrounds underneath new foreground colors.
